# React Basics

A structured collection of React lessons, exercises, and projects created while learning modern front-end development.

## About This Repository

This repository follows a practical React learning path, beginning with React fundamentals and progressing through bundling, deployment, hooks, routing, Redux, Tailwind CSS, and a major project.

## Learning Path

- **Day01:** React introduction and fundamentals
- **Day02-Day03:** Bundlers and deployment
- **Day04-Day05:** Component-based development with a Myntra-inspired interface
- **Day06-Day13:** Hooks, effects, callbacks, memoization, refs, context, routing, and custom hooks
- **Day14-Day16:** Redux, advanced Redux patterns, and API integration
- **Day17-Day18:** How React works and unique keys
- **Day19:** Tailwind CSS with React
- **Day20:** Major React project

## Getting Started

1. Clone the repository:

   ```bash
   git clone https://github.com/prbharti25/React-basics.git
   ```

2. Open the project in VS Code.
3. Enter the relevant lesson folder.
4. Install dependencies when a lesson contains a `package.json` file:

   ```bash
   npm install
   ```

5. Start the development server using the script defined by that lesson:

   ```bash
   npm run dev
   ```
